# App 审核备注（App Review Information → Notes）

> 把下面这段直接粘进 App Store Connect 的「审核备注」框。

---

```
【关于账号】
本 App 无需登录，没有账号体系，也没有服务器。审核时不需要演示账号，
打开即可看到全部功能。

【如何测试核心功能】
本 App 的核心是「把薪资换算成实时滚动的数字」，默认设置下即可看到效果，
无需任何额外配置。如需完整体验：

1. 打开 App，首个标签页「总览」会显示今日到手金额。
2. 「统计」标签页：月历上长按某一天，可以记请假或加班。
3. 「我的」标签页：可配置薪资构成（按月 / 按日 / 按时）、工作日方案
   （双休含调休 / 大小周 / 单休）与工作时段。
4. 锁屏小组件：长按锁屏 → 自定 → 选中时间下方区域 → 在列表中选择
   「月薪鸭」→ 可选矩形或行内样式。iOS 的锁屏小组件只支持这两种形态，
   主屏幕小组件已在本版本中下线。

【关于网络请求】
App 只在一处联网：获取中国大陆法定节假日与调休安排，用于「双休（含调休）」
工作日方案。请求的是公开数据集（GitHub 上的 NateScarlet/holiday-cn），
通过 jsDelivr CDN 获取，请求内容只有年份数字，不携带任何用户信息。
若审核环境无法访问该 CDN，App 会退回使用内置缓存，不影响其余功能。

【关于数据存储】
App 不收集任何数据，无第三方 SDK，无统计埋点，无广告。
用户数据只存在本机，以及（用户开启同步时）其本人的 iCloud 私有空间。

【关于隐私】
隐私政策：https://borry5.github.io/MoonSalary-docs/privacy/
技术支持：https://borry5.github.io/MoonSalary-docs/support/

【关于 macOS 版本】
本 App 为 iOS / macOS 双平台。macOS 端形态是菜单栏常驻小工具。
如需在 macOS 上审核，请注意菜单栏图标的显示位置（屏幕右上角）。

【联系方式】
如有任何问题，请通过 borrymeng5@gmail.com 联系。
```

## 补充：可能被追问的点

| 审核员可能问 | 建议答复 |
|---|---|
| App 是否需要账号？ | 不需要。无账号、无服务器。 |
| 薪资数据会不会上传？ | 不会。只存本机与用户自己的 iCloud 私有空间，开发者无法访问。 |
| 为什么需要读取设备信息？ | 只用于在 iCloud 设备名录里区分设备，哈希后仅存于用户自己的 iCloud，不用于追踪，不上传开发者。 |
| App 内是否有外部链接？ | 只有隐私政策与技术支持两个固定 HTTPS 链接，无网页浏览器、无引导下载其他 App。 |
| 是否有 App 内购买？ | 没有。 |
| 是否含广告？ | 不含。 |
