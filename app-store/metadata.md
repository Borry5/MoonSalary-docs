## 应用名称

> 上限 30 字符

```
打表上班
```

字符数：**4**

> **ASO 提示**：30 字符的上限只用了 4 个，很浪费。
> 商店名称支持「主名 - 副标题」的形式，建议考虑
> `打表上班 - 实时进账工资条`（14 字符），
> 能多覆盖「实时 / 进账 / 工资条」这几个高意图词。
> 现已改为纯「打表上班」，若想用带尾巴的版本，改这一处即可。

## 关键词

> 上限 100 字符，英文逗号分隔，逗号后不要空格

```
月薪,工资,工资条,收入,实时,进账,日薪,时薪,年薪,打卡,考勤,工时,加班,加班费,请假,日历,倒计时,锁屏小组件,桌面小组件,记账,退休,存钱,打工人
```

字符数：**76**

> **为什么这样排**：商店名称改成「打表上班」后，
> 名称里**不再含**「月薪 / 工资 / 收入 / 实时 / 进账」这几个词，
> 所以必须把它们全部补进关键词 —— 这是改名带来的直接代价。
> 同时补上「打卡 / 考勤 / 工时」，因为「打表上班」这个名字天然会吸引
> 找考勤、排班类 App 的用户，把这些词接住能提高转化。
>
> 名称与副标题里已有的词不必重复（Apple 会一并索引）。
> 副标题「把月薪换算成看得见的每秒收入」已覆盖「月薪 / 换算 / 收入」。

## 描述

> 上限 4000 字符

```
月薪鸭把月薪换算成看得见的每一秒。

每亮一次屏，都能看到今天又赚了多少——数字在锁屏上实时滚动，工作时段内一秒钟都不停。

【锁屏上直接看】
iPhone 锁屏小组件，矩形和行内两种样式。不用解锁，瞄一眼就知道今天到手多少。

【Mac 菜单栏常驻】
macOS 版把数字摆在菜单栏上，写代码、写文档的时候余光扫一下，进度心里有数。

【三种工作日口径】
· 双休（含调休）：自动跟随中国大陆法定节假日与调休安排，每年放假通知一出就能算准
· 大小周（不含节假日）
· 单休（不含节假日）
法定节假日数据来自公开数据集，跟随国务院办公厅的放假安排更新。

【薪资三档联动】
按月、按日、按时三种口径互通，以日薪为真值。你填月薪，它帮你换算日薪和时薪；你填时薪，它反推月薪。不用自己按计算器。

【统计与日历】
月历上长按某一天，可以记请假或加班。年度进度、今年累计到手一并算清，还能跟「大佬」比一比要搬多少天砖。

【iCloud 私密同步】
薪资方案和工作记录自动在你的 iPhone 和 Mac 之间同步。数据存在你自己的 iCloud 私有空间里，开发者没有任何途径读取。

【关于隐私】
月薪鸭没有账号，没有服务器，没有统计埋点，没有第三方 SDK，App 内也没有任何广告。你的薪资是多少、什么时候上班、哪天请了假——这些只有你和你的设备知道。

【关于算法】
当月按该月的实际工作日数摊算日薪，所以 2 月和 3 月的日薪会略有差别，这是按真实工作日计算的结果。

—— 

"小小的脑袋装着大大的发财梦。"
```

字符数：**约 620**
