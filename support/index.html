常见问题

锁屏小组件怎么添加？

长按 iPhone 锁屏 → 点「自定」→ 选中时间下方的小组件区域 → 在列表里找到「月薪鸭」→ 选矩形或行内样式 → 完成后点「完成」。iOS 的锁屏小组件只支持矩形和行内两种形态。

数字不动，或者显示的是 0

按顺序排查：

  1. 确认「我的 → 薪资 → 薪资构成」里已经填了金额，且选的是「按月」「按日」还是「按时」。
  2. 确认「我的 → 工作日与时间」里的工作时段设置正确。当前时间不在工作时段内时，显示的是当天的结算结果。
  3. 如果是「双休（含调休）」方案，确认当天不是法定节假日。
  4. 锁屏小组件由系统按自己的节奏刷新，通常几分钟一次。想要立刻更新，打开一次 App 即可。

日薪是怎么算出来的？

以日薪为真值，其余口径互相换算。当月按该月的实际工作日数摊算，所以不同月份的日薪会略有差别——2 月和 3 月的工作日数不一样，这是正常的。

iCloud 同步没有生效

  1. 确认「设置 → 你的名字 → iCloud」里已经登录，且月薪鸭的 iCloud 开关是打开的。
  2. 确认 App 内「我的 → iCloud 同步」是开启状态。
  3. iCloud 键值同步是「尽力而为」的最终一致，不是即时的。多等一会儿，或者把 App 切到后台再切回来。
  4. 两台设备需要登录同一个 Apple ID。

换手机 / 换电脑后数据还在吗？

在的话。只要新设备登录同一个 Apple ID，并且之前开启过 iCloud 同步，数据会自动同步过去。如果换机前没开过同步，旧数据只存在旧设备上，无法找回。

怎么彻底删除我的数据？

  • 本机数据：删除 App。
  • iCloud 数据：打开「设置 → 你的名字 → iCloud → 管理账户存储」，找到月薪鸭并删除。也可以先在 App 内关闭 iCloud 同步再删 App。

月薪鸭没有服务器，也没有账号，所以不存在需要联系开发者删除的云端数据。详见隐私政策。

有 Mac 版吗？

有，是菜单栏常驻的小工具。macOS 版正在准备上架 Mac App Store，上架后会在 App 内提示。

节假日数据是哪来的？准不准？

用的是公开的中国大陆节假日数据集（NateScarlet/holiday-cn），跟随国务院办公厅每年发布的放假安排更新。如果发现某年安排有出入，欢迎发邮件告知。

会收集我的数据吗？

不会。没有账号，没有埋点，没有广告，没有第三方 SDK。详见隐私政策。
